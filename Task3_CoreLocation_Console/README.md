**Вариант 25**

## Цель работы
Изучить библиотеку CoreLocation для определения географического местоположения устройства.

## Что такое CoreLocation?
CoreLocation — это фреймворк в iOS, который предоставляет разработчикам доступ к информации о географическом положении устройства через GPS, Wi-Fi, Bluetooth и сотовые вышки.

## Реализованный функционал

-  Создание CLLocationManager
-  Запрос разрешения на использование геолокации
-  Настройка делегата для получения обновлений
-  Определение текущих координат (широта, долгота)
-  Вывод координат в консоль
-  Отслеживание изменения статуса авторизации
