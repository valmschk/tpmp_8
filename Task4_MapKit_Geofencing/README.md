# Задание 1.4. iOS приложение с функцией определения местоположения по карте (MapKit + CoreLocation)

**Вариант 25**  
**Выполнила:** Мещенко Валерия Вячеславовна, 2 курс 10 группа

## Цель работы
Изучить библиотеки MapKit и CoreLocation для отображения карты, определения местоположения пользователя и создания геозон.

## Что такое MapKit?
MapKit — это фреймворк iOS для встраивания карт в приложения, добавления аннотаций (меток), рисования overlays (окружностей, полигонов) и отслеживания региона.

## Реализованный функционал

-  Отображение карты (MKMapView) с центровкой на пользователе
-  Отслеживание местоположения пользователя
-  Создание геозоны (CLCircularRegion) с радиусом 500 метров
-  Визуализация геозоны на карте (MKCircle)
-  Добавление аннотации (MKPointAnnotation) — "булавка"
-  Отслеживание входа/выхода из геозоны
-  Настройка отображения оверлеев (MKCircleRenderer)

## Что такое геозона?
Геозона — это виртуальная граница вокруг реального географического местоположения. Приложение может отслеживать вход и выход устройства из этой зоны.
