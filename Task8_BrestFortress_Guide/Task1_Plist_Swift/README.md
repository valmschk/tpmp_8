## Цель работы
Изучить механизм хранения данных в формате Property List (.plist) на языке Swift.

## Что такое .plist?
Property List — это формат файлов (обычно XML) для хранения простых структурированных данных. Используется для хранения настроек приложения, конфигураций и небольших объемов данных.

## Реализованный функционал

-  Чтение данных из .plist при запуске приложения
-  Отображение данных в UILabel
-  Ввод нового значения в UITextField
-  Сохранение данных в .plist по нажатию кнопки SAVE
-  Атомарная запись (write(to:atomically:))
