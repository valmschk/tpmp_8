## Цель работы
Научиться работать со встроенным в Xcode средствами для работы с базами данных – Core Data. Научиться добавлять, удалять и получать объекты из базы данных.

## Реализованный функционал

-  Создание модели данных (.xcdatamodeld) с сущностью Students
-  Добавление студентов в базу данных
-  Отображение списка студентов в UITableView
-  Удаление студентов (свайп влево)
-  Сохранение данных после закрытия приложения
-  Архитектура MVC

## Модель данных (Core Data)

**Сущность:** `Students`
| Атрибут | Тип | Назначение |
|---------|-----|------------|
| name | String | Имя студента |

## Интерфейс

| Компонент | Назначение |
|-----------|------------|
| UITextField | Ввод имени студента |
| UIButton | Добавление студента |
| UITableView | Отображение списка |
