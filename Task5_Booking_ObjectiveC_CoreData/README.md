# Задание 1.5. Система бронирования авиабилетов (Objective-C + CoreData + MapKit)

**Вариант 25**  
**Выполнила:** Мещенко Валерия Вячеславовна, 2 курс 10 группа

## Технологии

| Библиотека | Назначение |
|------------|------------|
| CoreData | Хранение данных о рейсах в SQLite |
| MapKit | Отображение карты и маркеров |
| CoreLocation | Геолокация и выбор города на карте |

## Реализованный функционал

-  Выбор города на карте (длинное нажатие → геокодирование)
-  Автоматическое заполнение полей "Откуда"/"Куда"
-  Хранение рейсов в CoreData (SQLite)
-  Поиск рейсов по городам
-  Отображение списка рейсов в UITableView
-  Настройка фреймворков в Build Phases
