# Задание 2.2. Приложение бронирования авиабилетов

**Вариант 25**  
**Выполнила:** Мещенко Валерия Вячеславовна, 2 курс 10 группа

## Технологии

| Библиотека | Назначение |
|------------|------------|
| CoreData | Хранение рейсов (SQLite) |
| MapKit | Отображение карты и маркеров аэропортов |
| CoreLocation | Геолокация и выбор города на карте |
| URLSession | Запрос погоды с OpenWeatherMap |

## Функционал

-  Выбор маршрута на карте (длинное нажатие → геокодирование)
-  Поиск рейсов по городам (фильтрация CoreData)
-  Список рейсов в UITableView
-  Прогноз погоды в аэропорту через OpenWeatherMap API
-  Локализация на 3 языка (русский, английский, белорусский)

## Локализация

|------|------|-----|
| Русский | ru.lproj/Localizable.strings | ru |

## Модель данных (CoreData)

**Сущность:** `Flight`
| Атрибут | Тип | Назначение |
|---------|-----|------------|
| cityFrom | String | Город отправления |
| cityTo | String | Город назначения |
| company | String | Авиакомпания |
| duration | String | Длительность |
| price | Float | Цена |
