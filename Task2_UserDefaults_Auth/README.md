# Задание 1.2. Приложение с авторизацией и хранением данных в NSUserDefaults

**Вариант 25**

## Цель работы
Изучить механизм хранения пользовательских данных с использованием NSUserDefaults (UserDefaults) на языке Swift.

## Что такое NSUserDefaults?
UserDefaults — это простой интерфейс для хранения небольших данных в виде пар "ключ-значение". Данные сохраняются даже после закрытия приложения.

## Реализованный функционал

-  Переключение между режимами **Login** и **Sign Up** (UISegmentedControl)
-  Проверка согласия с правилами (UISwitch) при регистрации
-  Сохранение логина и пароля в UserDefaults
-  Флаг авторизации "isLoggedIn"
- Проверка введенных данных при входе
-  Автоматическое сохранение сессии
